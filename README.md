# Automatic Street-Lighting Control System

B.Sc. project, American International University-Bangladesh (AIUB).

## Overview

An energy-efficient street-lighting controller that switches and dims lights automatically based on ambient light, reducing wasted energy compared to fixed-schedule lighting.

Project one-pager: [featured-streetlighting.pdf](featured-streetlighting.pdf)

## How it works

- An LDR (light-dependent resistor) senses ambient light levels
- Control logic switches the lights ON/OFF automatically at dusk/dawn
- Dimming logic adjusts output to save energy when full brightness is not needed

## Skills demonstrated

Analog sensing · control logic design · energy-efficient system design · circuit prototyping and testing
